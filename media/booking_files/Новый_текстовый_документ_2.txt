Разработка системы бронирования студии видеозаписи "Джалинга"

Проблема: Отсутствие автоматизированной системы для бронирования времени работы в студии видеозаписи, что приводит к хаотичному расписанию, конфликтам и потере времени на координацию.

Решение: Создание веб-приложения с функцией бронирования слотов, уведомлениями, календарем и управлением доступом.

Что нужно сделать:

Для студентов:
Личный кабинет с историей бронирований
Система уведомлений о подтверждении/отмене брони
Просмотр доступных слотов в реальном времени

Для преподавателей:
Приоритетное бронирование
Управление групповыми заявками
Календарь планирования съемок

Для администраторов:
Управление расписанием работы студии
Настройка параметров бронирования
Мониторинг использования оборудования

Техническая реализация:
API для интеграции с календарными сервисами
Система автоматических напоминаний
Резервное копирование данных бронирований

Это тема моей ВКР. Студия самозаписи на базе вуза. Единственное, что нужно добавить в задание еще одну категорию пользователей - внешние гости, не относящиеся напрямую к вузу. Думаю у них права должны быть типа студента + Управление групповыми заявками. Запомни это как основное задание.
